# Analytic-uncertainty-in-observational-epidemiology
Analytic uncertainty in observational epidemiology: a specification curve analysis of C-reactive protein and mortality

This repository contains the complete, self-contained code to reproduce the analysis and figures presented in the accompanying paper.

No manual data download is needed: the code contains direct download of data from the NHANES (https://wwwn.cdc.gov/nchs/nhanes/).
